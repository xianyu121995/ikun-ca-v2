# 参考图交互评审版

用户于 2026-10-15 提供深蓝黑色交易终端参考图，要求先制作可点击版本，试用后继续修改。本次沿用猎手监控页面职责，借鉴参考图的外壳和视觉，不接管猎手项目监控业务。

## 视觉和布局

- 深蓝黑底、青绿色主操作、细边框、圆形项目标识、紧凑表格和带圆点的状态标签。
- 演示外壳包含品牌、三个导航入口、顶部面包屑、通知、演示账号、北京时间时钟和“交互设置”。其他页面入口明确说明由各自窗口提供；未接入的账号设置、退出有禁用原因。
- 页面顶部使用五项发现项目统计。统计仅来自注入数据和本地回调结果，不伪造运行中/系统正常。
- 右侧资料面板从整个内容区顶部展开；默认隐藏，点击编辑后显示，关闭恢复全宽。面板表单内部滚动，底部保存/确认按钮保持可达。
- 点击编辑直接显示项目资料表单；按用户反馈移除“发现信息”及资料页签栏，不展示技术 ID 区块。
- 手机使用顶部三个业务入口、整行搜索和下一行筛选；表格内部横向滚动。

## 可点击内容

搜索/时间/评分/状态、重置、排序、编辑、评分与备注保存、确认/取消加入、猎手管理、导航说明、通知说明以及演示设置均有交互。设置可切换演示身份、403、超时、409、pending、unknown 和页面加载/空/失败状态。

`ReferencePreviewFrame.tsx` 仅为本地参考图评审外壳，不替换或复制共享 `@ikun/ui` 源码。颜色覆盖只作用于该预览容器，不修改全站 globals/layout。原型仍不请求业务 API、不写数据库或修改监控。
