# 三页定稿统一交互预览

按用户“查看三个最终定稿、统一字体颜色按钮并集成后交互”的要求，在 `packages/ui` 内完成独立组合。遵循 `phase2-spec-v1.0.0` 的视觉、公共组件和文件归属；未合并业务分支，未改网站根路由、根配置或锁文件。之前的 UI0 冻结提交和验证记录保持原样。

## 启动

在 `ikun-ca-v2-worktrees/website` 中运行，使用仓库已固定的 Node / pnpm 和本包依赖：

```sh
export PATH="/Users/lvlei/Documents/ChatGPT/ikun.ca开发/ikun-ca-v2/.tools/node/bin:$PATH"
pnpm --dir packages/ui preview:review -- --port 3255
```

打开 `http://127.0.0.1:3255`。左侧只有三个业务入口：`/`、`/hunter`、`/tracking`。支持浏览器后退、前进、直接刷新路由；服务仅绑定 `127.0.0.1`，Ctrl+C 退出。没有 HMR，修改后重启并刷新。

所有页面的 `@ikun/ui` 都使用当前公共组件；仅在预览构建中把页面各自的 AppShell 换为内容容器，由外层单个真实 AppShell 提供导航。CSS module 使用构建器的 local-css 作用域。构建不依赖根 Next 配置。

## 统一项与保留项

- 统一使用公共主题字体，正文及搜索框 13px，桌面标题 22px，次级文字按层级保留。普通按钮 36px，表格紧凑按钮 28px，圆角 6px。文字链接和大型统计卡保留原控件形态。
- 背景、面板、边界、输入框、主按钮和危险操作全部引用公共 token。评分统一为 S 绿、A 蓝、B 紫、C 琥珀、D 灰；B 级原色值提取为公共 CSS 变量，基础组件原外观不变。
- 统一搜索、焦点、对话框、错误和提示样式；保留原页面的受控弹窗、保存等待、防重、校验、二次确认等回调。猎手表操作列扩大到 180px，避免统一字号后重叠；窄屏表格在容器内滚动。
- 保留主页最近三项事件、小时字段、日期筛选和每页九项；保留猎手 V3 高密度表格、点击研究后才展开资料、用户名管理猎手；保留项目监控五张统计卡、备注优先、纵向推文和每页六条、点账号总数打开管理。

## 可体验范围

可搜索、筛选、排序、翻页、编辑演示资料、保存、查看空状态、加载和失败重试，操作原页面提供的确认流程。主页“演示设置”和猎手“测试页面状态”保留，便于检查交互状态。

数据只在当前页面的 React 内存中。切页或刷新会恢复演示数据；猎手页模拟加入监控不会向另一页传递真实任务或共享业务数据。没有登录会话、真实采集、API、数据库、定时任务或持久化。预览不包含登录和账号中心的业务接入；已有公共视觉组件保持可用。

服务只提供 HTML / JS / CSS 和三个 GET / HEAD 页面；其他路径 404，写入请求 405。CSP `connect-src 'none'`，不会连接业务服务。不读取 `.env`、监控脚本、业务数据库或生产服务，不发布线上。
